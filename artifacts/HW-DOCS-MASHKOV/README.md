# Weather MCP

## Назначение

Локальный MCP-сервер на Node.js, который предоставляет погодные данные Open-Meteo и инструменты для оценки погодного риска при наружных работах. Связь MCP-клиента с сервером идёт через STDIO.

## Инструменты MCP

- `get_weather` — текущая погода и прогноз на 1–7 дней для города.
- `assess_weather_risk` — почасовая оценка риска для запланированных работ.
- `find_safe_weather_window` — поиск целочасовых окон для работ в указанном интервале.
- `compare_weather_windows` — оценка двух периодов и выбор периода с меньшим уровнем риска; при равном риске оба окна остаются без предпочтения, `selected_indices` пуст.

## Требования, установка и запуск

Нужен Node.js версии 20 или новее и npm. Каждый блок команд ниже выполняется из корня проекта:

```sh
cd weather-mcp
npm ci
npm run build
```

Запуск собранного сервера:

```sh
cd weather-mcp
npm start
```

Запуск исходников в режиме разработки:

```sh
cd weather-mcp
npm run dev
```

Сервер ожидает соединения MCP-клиента через STDIO.

## Тесты
