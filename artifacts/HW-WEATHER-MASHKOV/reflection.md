# HW-WEATHER-MASHKOV

## Черновик рефлексии для сдачи

В первой версии плана модель предложила переиспользовать разрешение города из старого сервиса, хотя оно могло принять единственный неточный результат геокодирования. Она также не передала сервису разобранные границы всего интервала поиска, что создавало риск пропустить крайние часы прогноза. Самым полезным оказалось замечание Critic о неточном городе: оно привело к отдельному правилу точного совпадения только для нового инструмента. Вмешательство разработчика потребовалось при согласовании схемы результата и передаче полного `SearchPeriod`, чтобы внутренние `Date` не попали в публичный JSON. После исправления плана Builder реализовал поиск, а Tester независимо подтвердил сборку, 38 прошедших тестов и реальный успешный вызов через MCP Inspector. Я переписал бы исходный промпт Planner так, чтобы он требовал сразу фиксировать сигнатуры между слоями, точную форму `structuredContent` и контрпример для каждого правила обработки ошибок. Ручная проверка также показала ограничение формы Inspector: значение `duration_hours: 0` пришлось отправить отдельным MCP stdio-клиентом, чтобы получить именно отказ входной схемы.

Это черновик на основе наблюдаемых артефактов. Перед сдачей автору работы следует проверить формулировки от первого лица и при необходимости заменить их собственным опытом.
